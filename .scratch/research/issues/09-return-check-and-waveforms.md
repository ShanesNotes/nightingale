# 09: What the return check reads

Type: grilling
Status: ready-for-agent
Blocked by: none

**Question:** Record 0004 returns each anchor at 06:55, but 17 of the 50 anchor quantities are rhythms, production rates or factors with no reading at that moment. Which check holds them?

Model default: the return check covers anchors that are readings; a rate or rhythm is held by the certificate and its healthy range. A superseding note goes in a new record, since a pass does not reopen a recorded decision.

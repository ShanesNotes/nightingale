# 09: What the return check reads

Type: grilling
Status: open
Blocked by: none

**Question:** Record 0004 says the return check reads each anchor's method and window, at each later 06:55. 17 of the 50 anchor quantities are rhythms, production rates or factors with no snapshot at that moment. What does the check read for each?

Model default: every anchor keeps its return check, read by its own method over its own window, ending at that morning. A day's production is read over the 24 h before it, and a rhythm's amplitude and phase over the same day. This reads the record as written, so no superseding record is needed. An anchor no window inside 48 h can read, such as red cell lifespan, was never a produced quantity's snapshot and moves to the parameters, as P25 does.

- [ ] Each of the 17 names the window its source used, or moves to the parameters with its reason
- [ ] Each anchor's within-subject variation matches that window (ticket 07)

- **Thermoreceptor doctest sentence (`crates/ng-contract/src/catalog.rs`).** Added `Only a body kernel may sample it.` directly above the `compile_fail,E0308` block on `SkinThermoreceptor::temperature` so the sentence names the exact mismatch rustc refuses.
- **Four mutant rows caught by exact row assertions (`crates/ng-contract/src/publication.rs`, `crates/ng-contract/src/skin_vessels.rs`, `tools/gate/mutants.d/00-base.toml`).**
  - `thermoreceptor-reads-at-the-height-site`: points to `publication::the_thermoreceptor_reads_the_landmarks_sampled_store_and_never_its_height_store`, whose fixture gives both the landmark's sampled store and its height store their own `Tissue::Skin` bed and zero-rate conduction so both base and mutant compile cleanly and the assertion catches `height` bound in place of `sampled`.
  - `skin-edge-reads-every-downstream-site`: points to `skin_vessels::downstream_if_in_reads_only_sites_in_its_set_even_when_every_end_holds_a_row`, which defines a `Blood`-wide field read through `ReadPort<Cardiovascular, PerSite<Beds<Skin>, Dimensionless>>` via `downstream_if_in` so both base and mutant compile cleanly and the assertion catches the extra non-skin edge bindings `(draining, vein)` and `(back, artery)` and unscaled non-skin flows.
  - `missing-store-reads-the-core-row` and `store-temperature-read-body-first`: `missing` (when `missing != Missing::CoreStore`) and `sent` add zero-rate `ports.conduction`, removing thermal `OrphanPool` refusals, and return `Result<CompiledBody, AdmissionError>` into `assert_refused_read`, so each mutant compiles cleanly and fails showing the exact wrong temperature row bound (`MT.core_temperature` at `Body`, or `MT.tissue_temperature` at `Body`).

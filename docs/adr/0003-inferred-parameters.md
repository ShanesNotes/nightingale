# A model may fill a gap in the packet, but every target rests on a source

Nightingale is a simulation for teaching and never informs the care of a real patient, so a labeled inference gives a learner more fidelity than leaving an unsourced mechanism out. A parameter or a number of the patient's day that no clinically reviewed source, primary or textbook, covers may carry an inference record: the model that made it, its reasoning, the population, the source records it reasons from and the search that found no source, frozen in the packet hash and displayed as inferred. Every target rests on the literature, because a check against a target the model made up would show only that the model agrees with itself.

## Considered options

- Literature only: rejected. A mechanism with one unsourced parameter would stay out of the body, or its region would stay grouped, and a learner would get less fidelity than the models can give.
- Inference counted the same as a source, targets included: rejected. A model's confident wrong number would pass as sourced, and a test against an inferred target would pass on the model's own agreement.
- Inference for parameters only, with the day fully sourced: rejected. The day the patient lives (record 0005) moves the body as a parameter does and is never a target, so a gap in it, such as how the day's sodium splits across meals, would stall the milestone with no gain in rigor.
- The search named only for a healthy range's inference record: rejected. Without it, the claim that no source covers a value could not be checked, and an inference could stand in for a source nobody looked for.

## Consequences

- An inference never changes in place. A better model makes a new inference record, which makes a new packet with a new hash.
- Available literature still comes first: primary data from the target population, then a textbook value, then inference. A textbook value fills a gap that only a gated or missing primary paper leaves, so the search an inference record names covers textbooks too. A source replaces an inferred value once one covers it, and every reviewed packet states how many inferred values it carries.
- An anchor never carries an inference. A healthy range or a within-subject variation carries one only to adjust a sourced one by a sourced shift, so it still rests on two sources, or, for an amount no method can measure, to reason from the sourced flows into and out of it (record 0004).
- The contract's value provenance gains an inferred kind, which an anchor refuses.

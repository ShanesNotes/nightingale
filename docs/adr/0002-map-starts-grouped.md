# The map starts grouped, and each split is earned

SRS section 5 described the body more finely than clinically reviewed literature can source, so the map now starts grouped. It splits a region only when a sourced check fails without the split, or when a clinician's question needs what happens inside the region and brings a sourced target for that behavior. A sourced check fails without the split when an anchor targets a part of the group, or when the group misses the check at every parameter value its sources allow.

## Considered options

- Only a clinician's question earns a split: rejected. A group that fails a sourced check could then only be refitted, and a refitted parameter hides a structural error.
- Any finer structure a textbook describes earns a split: rejected. It adds detail that no question asks for and no number supports.
- A split earned by a question may rest entirely on inferred parameters: rejected. Its new behavior would never meet the literature, so the rule that every target rests on a source (record 0003) would never reach a refinement.
- A sourced target only when the new behavior reaches the monitor, the chart or a lab: rejected. Almost every behavior worth a split reaches a reading, and the line would be argued again at every split.
- A split stays within a declared tolerance of the grouped body, as I11 first said: rejected. A split earned by a failing check exists to change the grouped behavior, so the old rule would hold it to the behavior it was meant to fix.
- The grouped body as the reference only where the new structure is not exercised: rejected. It is still a run's output used as a pass bar.
- A grouped region states only what it stands for: rejected. A learner shown the region's averaged behavior would have no way to know what it cannot show.
- A scenario that depends on a hidden behavior runs anyway, with the limit on screen: rejected. The learner would play a scenario whose teaching point cannot happen.
- Keeping the rule that no network is a single conduit: rejected. It would bring back detail that no question or failing check earned.

## Consequences

- A split keeps every regional total exact and every sourced check the grouped region passed, and it passes what earned it (I11). The grouped body is never the reference for a split: its behavior is a run's output, not a target, and when the two bodies differ it cannot say which one is wrong. A comparison with it is a report for review, not a pass bar.
- Each grouped region states the structures it stands for and the behaviors it cannot show because they happen only inside it. A scenario that depends on one of those behaviors is refused when it is built, and the body model carries the lists, so a debrief can show them.
- Section 5's network list is the reference anatomy. Groups name what they stand for in its words, and splits move toward it.
- A split also keeps the speed aim in section 6. A split that would slow the engine below it waits for a faster solver or a cheaper structure.
- At stage 1, the map holds the regions that the anchors and the stage 1 checks name, and nothing finer.
